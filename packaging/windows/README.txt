Bike Parts Inventory for Windows

How to run
1. Extract this ZIP file to any folder.
2. Run bikeparts.exe
3. Open http://localhost:8080 in your browser

Data location
- The app stores its SQLite database in the user config directory.
- On Windows this is typically:
  %AppData%\bikeparts\data.db

Notes
- Do not store the database in the extracted app folder.
- You can replace bikeparts.exe with a newer version without overwriting your data.
- If needed, set PORT or DB_PATH as environment variables before starting the app.
